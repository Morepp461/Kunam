# Favicon assets

Upload the approved CALERIS icon files here. The website references these paths:

- `favicon.svg`
- `favicon.ico`
- `favicon-16x16.png`
- `favicon-32x32.png`
- `favicon-48x48.png`
- `apple-touch-icon.png` (180x180)
- `android-chrome-192x192.png` (192x192)
- `android-chrome-512x512.png` (512x512)

A single high-resolution square source image can be used to generate the PNG sizes, SVG only if a vector source is supplied, and a multi-size ICO. Keep transparent edges if the source uses transparency.
