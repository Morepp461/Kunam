# CALERIS MASTERS

A motorsport roleplay platform built around competition, team management, car development, and an interconnected in-game economy.

## Current phase: Public landing page

Responsive public landing page built with Next.js App Router, React, TypeScript, and plain CSS.

## Stack
- Next.js 16 / React 19
- TypeScript
- Node.js 24
- Plain CSS (no UI framework)

## Development
```bash
npm install
npm run dev
```

## Quality checks
```bash
npm run lint
npm run typecheck
npm run build
```

Database integration and member actions are intentionally out of scope for the public landing page. Supabase architecture and migrations will be handled when the first database-backed feature is scoped.
