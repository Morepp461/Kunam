## Compatibility note

This is a **2025** model. It must not be labelled as an exact 2026-regulation chassis. UV availability is promising for texture-based livery, but production integration still needs:
1. The binary asset committed or hosted in the project’s approved asset storage.
2. Mobile/desktop GPU and loading-budget validation for this 3.1M-triangle model.
3. UV/material inspection against the intended body zones and sponsor placements.
4. A versioned optimized runtime asset, while preserving the original credited source file.

Do not replace this asset with a procedural primitive and describe it as hyper-realistic. The current application preview remains a procedural placeholder until the GLB is actually integrated and verified.
